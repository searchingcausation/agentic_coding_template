# Execution plans

One file carries both a substantial task's implementation plan and the state needed
to resume it: progress, decisions, failed approaches, verification, learnings, and
next step.

1. Copy [template.md](template.md) into [active/](active/) using a descriptive name.
2. Fill in the goal/spec, risk, authorization, steps, trade-offs, and verification.
3. Update actual progress and evidence at milestones and before handing off.
4. Promote confirmed, reusable learnings into their appropriate durable artifact.
5. Move the plan into [completed/](completed/) when acceptance criteria and required
   reviews are satisfied. Update affected links and run the relevant checks.

LOW tasks usually need no plan file. One-off NORMAL goals can be specified inside
the plan. HIGH tasks with independent review pending stay active and are not
merge-ready.

Both task directories start empty.
